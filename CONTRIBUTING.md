# Contributing

Thanks for helping improve `laranail/chrono`.

## Getting set up

```bash
composer install
composer test
composer lint
```

Requires PHP `^8.5` with `ext-intl` and `ext-calendar`.

## What must pass

- **Style** — `composer pint-fix` (Laravel Pint preset, `declare(strict_types=1)`). Note Pint writes
  `clone ($this, [...])` with a space; that is canonical here, so write it that way.
- **Static analysis** — `composer phpstan` runs two configs: level 8 with larastan for the Laravel
  shell, and **level 10 with strict rules and no baseline for `src/Core`**.
- **Architecture** — `composer deptrac` proves `src/Core` references no `Illuminate\*`, no `Carbon\*`
  and no other `Simtabi\Laranail\*` package, and that the module DAG holds. It runs through
  `tools/deptrac-guard.php` rather than deptrac directly, because deptrac exits 0 when it cannot
  parse a file.
- **Rector** — `composer rector` (dry run), pinned to the `php85` set.
- **Tests** — `composer test` (Pest). Add tests for new behaviour.

## Writing tests

Never call `now()`, `time()`, `date()` or `Carbon::now()` in `src/` — inject the PSR-20 clock. An
architecture test enforces this. Tests freeze the clock, so a DST assertion is reproducible forever.

Fixtures come in two kinds and must not be mixed:

- **Rule-based** — statutory DST (US, EU, AU) and historical events. Hard-code exact values.
- **Decree-based** — Morocco's Ramadan shifts, Iran, Chile, Egypt, Fiji, and moving religious
  holidays. Assert by *shape* and tag `->group('tzdata')`. These run in a separate weekly workflow so
  a mid-sprint tzdata bump on the CI image cannot turn the build red.

## Generated files

`src/Core/Enums/Timezone.php`, `TimezoneLegacy.php`, `TimezoneAbbreviation.php`,
`Timezone/Support/AliasMap.php` and `CountryZones.php` are generated by `laranail::chrono.sync`.
Never hand-edit them — change the generator. A byte-for-byte test asserts the committed files match
what the generator emits against the runner's tzdata.

## Pull requests

- Tests added or updated, and `composer test` passes
- `composer lint` is clean
- `CHANGELOG.md` updated under `## Next` for user-facing changes
- Docs updated under `docs/` if behaviour or public API changed
- Commits follow [Conventional Commits](https://www.conventionalcommits.org/)
- New commands follow `laranail::chrono.<command>` with a `chrono:<command>` alias
